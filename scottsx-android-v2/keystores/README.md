# Shared debug keystore (pinned)

Identical companion of `scottsx-android/keystores/debug.keystore` — both
apps share the package `com.scottsx.app`, so one (package, SHA-1) OAuth
registration covers v1 and v2 debug builds alike. See
`scottsx-android/keystores/README.md` for the rationale, fingerprints,
registration steps and regeneration procedure.
